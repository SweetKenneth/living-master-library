# LivingRoadmap install questions

1. What project/repository should the roadmap observe?
2. How many days without activity should count as stale intent?
3. Which files/directories should never enter evidence storage?
4. Which evidence in your environment counts as actual production shipping proof?
5. Which roadmap scoring fields matter most: value, revenue proximity, effort, creator energy, or dependency risk?
6. Who is authorized to confirm `shipped`, `abandoned`, or `superseded` states?

LivingRoadmap defaults to requiring explicit confirmation before `shipped` because implementation evidence is not the same thing as production truth.
